В этой лабораторной работе мы закрепляем навыки работы с Git, Markdown, терминалом и проектной структурой. Мы создаём новый GitHub-репозиторий с папкой Lab4_ISRPO_barakov, вручную через терминал формируем структуру проекта, включающую клиентскую часть с HTML-страницами, серверную часть на C# с интерактивным меню, папку docs с примерами Markdown и LaTeX, а также папку terminal_practice для отработки команд терминала. В ходе работы мы осваиваем частые коммиты и push, оформляем README.md и дополнительные документы с активным использованием Markdown, запускаем frontend в браузере и backend в терминале, а также добавляем скриншоты, подтверждающие выполнение всех этапов.
